Cortex should expose generalized knowledge as one bounded, inspectable geometric retrieval space rather than a collection of opaque topic silos.

The canonical base is knowledge.shared. It contains portable cross-agent knowledge and grows through active canonical records, record kind, descriptive titles, exact content, and bounded topic tags. knowledge.user is a separate local overlay for durable user-specific guidance. A caller may explicitly compose the shared base with that overlay, in base-first order, when the user context can affect the decision. Excluded spaces must contribute no direct hit, neighbor, or ranking signal. Project namespaces remain separate operational context and do not become hidden inputs to the shared geometry.

The current geometry is deterministic sparse retrieval, not a neural embedding and not an independent source of truth. Bounded title, tag, and indexed-summary features place selected active heads in one comparable coordinate system. Direct keyword matches remain ahead of related neighbors. Direct hits may contribute bounded expansion terms so a related record can fill remaining result slots even when it does not contain the original query phrase. Full record bodies, revisions, provenance, and lifecycle state remain authoritative in SQLite and are returned only by an exact typed read.

Search results are previews for agent judgment. Each preview must expose enough stable identity to request the exact body: effective namespace, record type, record ID, revision, title, compact summary, and ranking signal. The agent retains an in-context coordinate-to-revision map after exact reads, reuses a body only while that body remains in context and its revision is unchanged, and rereads a newer revision. Cortex does not need sticky read receipts or a duplicate hydrated-body cache.

Improve this space by curating canonical records and precise topic tags, not by copying raw conversations or fragmenting subjects into more namespaces. Evaluate representative queries with direct precision, related-neighbor recall, irrelevant-hit rejection, explicit-overlay isolation, exact-read success, bounded preview bytes, and deterministic repeatability. Geometry helps agents find possible context; it does not establish truth, authority, permission, or execution intent.

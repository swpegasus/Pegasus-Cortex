Do not infer the executable or version used by an already-running client from current configuration alone. Long-lived child processes, STDIO tool servers, language servers, and similar integrations can remain attached to an older executable after configuration or installation changes. Verify through a fresh client or task, require an observable call through the integration, and compare the integration-reported identity and version with a direct invocation of the selected installed artifact. Configuration text, successful parsing, registration state, and file replacement are not attachment proof.

## Installed product layout

Discover three independent absolute local roots from registration or the product manifest, never build-machine paths:

1. Program: replaceable `Applications/Worker`, `Applications/Desktop`, `Plugins`, and `Resources`; default `C:\Program Files\Pegasus\Cerebral`.
2. Data: mutable databases, settings, logs, models, and profiles; default `C:\ProgramData\Pegasus\Cerebral`.
3. Workspace: agent project folders; default `C:\CerebralProjects`.

Roots are independently configurable. Keep private runtime dependencies product-local; share only compatible contracts or portable tools.

Implementation boundary
CortexKnowledgeGeometry.SelectEndpoints(intent, traversal, identities?, options?,
cancellationToken) selects from the already admitted old chain graph. It has no
provider callback or IO. Normal SearchAsync/TraverseAsync, existing traversal
coordinates and scores, and graph construction remain unchanged.
Disabled selection returns the original ranked coordinates/scores and a null
selection score. Selection scores/features/reasons are separate from old scores.
Defaults: Enabled=false, limit=4, maxCandidates=128, diversityPenalty=.04,
CPU deadline=5000ms. Caller cancellation throws; internal time exhaustion returns
explicit partial status. Graph roots, paths, predecessor and query membership are
validated. The same cached graph is used for OFF/ON/replay comparisons.

Frozen v1 policy
Shared existing Unicode term/vector utilities are reused. No fixture strings,
gold labels, IDs, token allow/deny lists or depth-only bonus occur in the policy.
rootAnchor = .6*rootHeaderIntent + .4*rootFullIntent
retainedAnchor = rootAnchor*(root ? 1 : .55+.45*actualPathBottleneck)
selfSupport = .7*headerCoverageInSummary + .3*headerSummaryCosine
endpointEvidence = max(selfSupport, incomingHeaderAgreement)
uncorroboratedMention = max(0,fullIntent-headerIntent)*(1-selfSupport)
base = .4*retainedAnchor + .3*rootAnchor*endpointEvidence + .3*fullIntent
       - .08*uncorroboratedMention
Greedy selection subtracts .04*maximum full-vector cosine to selected endpoints.

Equivalence is conservative: a trusted full canonical-content SHA and full actual
provenance SHA, exact namespace/kind/revision/title/ordered canonical tags are all
required. Preview/vector resemblance is insufficient; unknown hashes do not
collapse. All aliases and coordinate decisions remain exposed. Full immutable
fixture content and actual persisted provenance supply these hashes; gold does
not. Unit checks preserve body order, negation, numeric/code/version, revision and
provenance distinctions.

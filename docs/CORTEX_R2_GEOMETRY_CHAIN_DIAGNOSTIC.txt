Traversal identity and path policy
-----------------------------------
Direct candidates are depth0. Identity is structured namespace/knowledge/record/revision;
caller Point.Key is ignored. New qualified nodes remain non-direct. Cycles/visited
coordinates are deduplicated. Admission is breadth-first at the first admitted depth,
using the best encountered same-depth score, then first query ordinal; this is not a
globally optimal path. Incomplete-depth proposals are discarded on early budget stops,
while attempted/completed query records remain explicit.
Each admitted non-seed names the actual querying predecessor and query ordinal;
that query's bounded returned-coordinate list proves membership. Parent references
reconstruct visited paths; only top4 paths are repeated in compact diagnostic reports.

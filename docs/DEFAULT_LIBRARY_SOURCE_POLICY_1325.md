# Default Library source policy addendum - 13.25

This additive baseline keeps the reviewed `03.20` seed as immutable history and
permits only compact, locally verified evidence for the focused Shared, Nexus,
Server, and Coder update.

Eligible additions are limited to:

- the exact unchanged Shared `421-a` package hash;
- the Shared proportional-verification policy and deterministic archive-helper
  source hashes;
- the bounded Nexus release manifest for its currently produced executable
  target;
- the bounded Server library release manifest;
- the Coder self-contained and thin-profile deployment manifests; and
- this addendum's source hash.

Manifest evidence supports only the claims explicitly projected into curated
records. Source-supported runtime identifiers remain distinct from produced
release inventory. Compatibility or readiness never grants deployment,
installation, trust, identity, namespace, or execution authority.

External operational access channels, host administration state, coordination
receipts, raw command or chat output, credentials, private reasoning, binaries,
package caches, installer payloads, and executable manifest content remain
ineligible. Evidence references and hashes may identify an artifact without
copying its bytes into the seed or package.

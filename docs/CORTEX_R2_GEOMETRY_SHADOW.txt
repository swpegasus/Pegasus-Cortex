researchRoot must be the exact canonical generation directory under that owner's
ConfigDirectory; it cannot select an old database or arbitrary storage root.
No namespace or consent is inferred. Eligible records remain exact reviewed
shared/project knowledge revisions; no personal data or historical backfill.
The configfile and parent must have the existing protected current-owner policy.
The enabled lane creates only missing private research directories; existing
ACLs/owners/bindings are admitted strictly and never repaired or weakened.
An enabled file is bounded to512KiB, with unique properties and bounded exact
profile/options. Null/missing identity fields are rejected before attachment.
Malformed, unavailable or unsafe configuration and research init/root/binding
faults expose a bounded disabled issue and leave the original provider selected.
Ordinary provider failures/cancellation are never converted to research success.
